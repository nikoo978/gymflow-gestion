# V.1.03.1

Corrección funcional de Usuarios/roles antes de avanzar con V.1.04.

- Admin/Coadmin ven todos los emails registrados en la PWA.
- El vínculo parte de la cuenta PWA y apunta a una ficha Cliente/Profesor existente.
- Ya no se cargan emails PWA desde Clientes ni Personal.
- Cada registro crea un evento persistente para administración.
- El Admin master recibe Web Push de nuevas cuentas cuando tiene notificaciones activadas.
- La campana mezcla esos registros con el resto de eventos recientes.
