# V.1.04

Biblioteca de ejercicios + separación visual estricta por rol.

- Admin/Coadmin usan exclusivamente el panel administrativo.
- Profesor usa un shell propio con Inicio, Alumnos, Ejercicios y Accesos.
- Cliente usa un portal PWA mobile-first y sigue leyendo sólo su información mediante RPC.
- Admin/Coadmin pueden abrir una vista previa de Profesor y Cliente sin cambiar permisos.
- Nueva biblioteca de ejercicios con grupos musculares, imagen/video por URL, series, repeticiones, descanso y ejercicios personalizados.
